TO DOWNLOAD: Press "Download CustomPvP U", then press "View raw" which acts as a download button.
RENAME FILE: Rename the file called "Rename with your MC TileID" with one of the TitleIDs at the end of this README file (EUR = European, NA = North America/America, JP = Japan).
PLACE FILE: Insert your SD Card whatever device you use to make modifications on your SD Card, and on the root of the SD Card, GO INSIDE THE FOLDERS: wiiu > sdcaffine. Place the folder which you renamed its name with at the root of the folder "sdcaffine".
MAKE SURE: SDCaffine is ACTIVATED, and you have it already downloaded as an AROMA PLUGIN.
